# Alves Renovation — Shopify theme files

Arquivos do site da Alves Renovation instalados no tema Horizon da loja Shopify
(alvesrenovations.com). Use como cópia de segurança ou para reinstalar o site em outro tema.

- `layout/alves.liquid` — layout próprio do site (cabeçalho, rodapé, CSS/JS)
- `sections/alves-*.liquid` — seções editáveis no editor da Shopify
- `sections/alves-header-group.json`, `alves-footer-group.json` — menu e rodapé
- `templates/index.json` — página inicial
- `templates/page.alves-*.json` — páginas de serviço (cada página da loja usa o modelo com o mesmo sufixo)
- `templates/page.contact.json`, `templates/404.json` — contato e erro
- `assets/alves.css`, `assets/alves.js` — estilos e interações

As fotos ficam na área de Arquivos da Shopify (nomes `alves-*.jpg/png`).
Os leads do formulário chegam por e-mail pelo formulário de contato da Shopify.
